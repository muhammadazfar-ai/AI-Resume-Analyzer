\# AI Resume Analyzer 🚀



An AI-powered Resume Analyzer built using Python, Streamlit, and Large Language Models (LLMs).  

The application analyzes resumes, extracts skills, evaluates strengths and weaknesses, and generates an AI-based improvement report.



\## 📌 Features



\- 📄 Upload Resume (PDF)

\- 🤖 AI-powered resume analysis

\- 🔍 Extract technical skills

\- 📊 Resume scoring

\- ✅ Identify strengths

\- ⚠️ Identify weaknesses

\- 💡 Provide improvement suggestions

\- 📈 Generate career recommendations



\## 🛠️ Technologies Used



\- Python

\- Streamlit

\- Groq API / LLM

\- PyMuPDF

\- Pandas

\- Regular Expressions
